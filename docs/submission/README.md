## Project description

RELiV is a smart preventive health screening kiosk designed for campuses, workplaces, gyms, and community spaces. It brings together autonomous vital screening, instant wellness summaries, and a paperless digital report experience in a compact, accessible format.

From the live website, the kiosk is described as a 3-minute health check that measures blood pressure, SpO₂, temperature, body metrics, and wellness indicators, with multilingual support for English, Hindi, and Bengali.
